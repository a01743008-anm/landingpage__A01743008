# Tecatex Aerospace - Landing Page Oficial

Este repositorio contiene los archivos fuente del landing page estático para el proyecto aeroespacial **Tecatex Aerospace**.

## 📁 Estructura del Proyecto

```text
├── index.html   # Estructura principal de la página HTML
├── styles.css   # Estilos en cascada (Paleta oficial monocromática: Negro Espacial, Gris Cósmico, Blanco Lunar)
└── README.md    # Documentación e instrucciones
```

## 🚀 Guía de Despliegue en GitHub Pages

Para publicar esta página web de manera gratuita con GitHub Pages, sigue estos sencillos pasos:

1. **Crear Repositorio:**
   - Ve a GitHub y crea un nuevo repositorio (por ejemplo, `tecatex-aerospace`).

2. **Subir los Archivos:**
   - Sube los archivos `index.html` y `styles.css` a la rama principal (`main` o `master`).

3. **Activar GitHub Pages:**
   - Entra a la pestaña **Settings** (Configuración) de tu repositorio.
   - En el menú lateral izquierdo, selecciona **Pages**.
   - En la sección **Build and deployment** -> **Branch**, selecciona `main` (o `master`) y la carpeta `/ (root)`.
   - Haz clic en **Save**.

4. **¡Listo!**
   - En unos momentos, GitHub generará tu enlace público (ej. `https://tu-usuario.github.io/tecatex-aerospace/`).
